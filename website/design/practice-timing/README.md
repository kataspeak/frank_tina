- 画面と操作: `../../static/practice-timing/`。

## 動作

上段の横向きスピーカーから右へ広がる音波と波形、下段の人物の口パクと波形は実際のRive描画。HTML側にボタン・スライダー・字幕を置く。

RiveのModel・Speak（各2秒）、Offset（位置用1秒）、Phrase Pattern（波形選択用1秒）の4タイムラインを、ブラウザ側の共通時計で制御。2段とも24本の同じ波形。発話開始時刻×108 pxを下段に加算し、時間の重なりを表す。口パクは既存のFrank_mouth_close.png・Frank_mouth_open_half.png・Frank_mouth_open.pngの3枚をSoloで切り替える。発話終了時は閉じた口に戻る。

何も押さなければ、お手本2秒＋設定間隔で繰り返す。「話す」を押すと2秒間発話し、両段が終わってから比較用の0.45秒の静止を経て次へ進む。この静止はウェブ説明用の演出。再生間隔変更は次の周から反映。ゆっくり表示は時間を半分の速さで進める。一時停止・リセットあり。画面外では時間を進めない。動きを減らす設定では停止状態で開始し、利用者が再生できる。音声・マイク・録音・採点は使わない。

間隔0〜2秒はユーザーの構想を試すための説明用範囲。現行アプリの0.5〜1秒とは異なることを画面の補足に明記。速度メニュー・難易度・カウント・睡眠はこの試作の範囲外。

## 制作上の制約

初版は仮イラストを使用。その後、ユーザーから既存画像のRiveへのアップロード許可を受け、口パクPNG3枚をアップロードして差し替えた。旧図形は編集用ファイルのArchived placeholderグループに非表示で保管。

Rive runtimeは既存サイトと同じローカル2.43.1に固定。現在使用できるpause/scrub APIで操作する。将来のメジャー更新で廃止予定の警告があるため、ランタイム更新時はデータバインディングまたはステートマシンに移行する。

サイト全体のビルドは既存のA1-49注釈パース問題があるため、この独立ページをローカル静的サーバーで確認。公開サイトへのデプロイはしていない。

## 確認済み

- 実際のブラウザでRiveのロード、スピーカー、口、上下の波形の描画を確認。
- お手本中と終了後の「話す」を操作し、それぞれの表示を確認。
- 間隔スライダーの0秒・2秒、繰り返し、一時停止、最初からを確認。
- スマートフォン幅375pxで横はみ出しなし。
- JavaScript構文とgit diffの空白エラーを確認。

スピーカーは🔊を参考にした横向きの形。本体の回転キー31件を削除して固定し、3本の開いた弧の明暗で音波が外へ広がる様子を表す。再生終了時は弧が消える。

## 3フレーズの切り替え

Good morning. → How are you? → See you later. の順。未発話なら同じ英文・波形を反復し、発話終了後に次へ進む。3つ目の次は先頭へ。画面上に現在の英文・番号・3つの進行表示を置く。Phrase Patternタイムラインで上下24本の高さを3種類に切り替える。波形は実音声の解析結果ではなく模式図。表示時間は各2秒で統一。音声再生は引き続きなし。ブラウザで未発話時の保持と1→2→3の遷移を確認。

## 配色

## ホームページへの組み込み

ホームの #feature-shadowing に同一オリジンのデモを埋め込む。embed=1では単独デモのページ見出しを省略し、ホーム側の説明から直接操作できる。内容の高さを通知して枠を調整し、画面外では進行を休止。3フレーズとスライダー、口パクは同じ実装を共有。build.pyはこのデモのindex.htmlだけを明示的に配信対象へ追加。

確認URL: http://localhost:4321/ja/#feature-shadowing 。キャッシュ済み教材を用いてホームを再生成し、埋め込み上で発話後の次フレーズへの遷移を確認。全体ビルドは引き続きA1-49の既存注釈形式で停止するため未完了。公開サイトへの反映は行っていない。
