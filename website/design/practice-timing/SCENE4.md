# 場面4：難易度ごとの練習メニュー

ホームの場面3の直後に配置。`#feature-difficulty-speed` と従来の `#feature-difficulty-repeat` の両方から到達する。同じ How are you? の難易度と方式を切り替え、メニューの構成と進み方を比較する。

## 採用した初期設定

| 難易度 | 回数方式 | 速度方式 |
| --- | --- | --- |
| 簡単 | 1回 | 1.0 |
| 普通 | 2回 | 0.8 → 0.8 → 1.0 |
| 困難 | 3回 | 0.6 → 0.6 → 0.6 → 0.8 → 0.8 → 1.0 |

難易度は本人がフレーズごとに設定するものと明記。回数と速度を同時に掛け合わせず、別方式として切り替える。アプリで設定値を変更できることは補足し、デモでは初期値を比較する。

## 動き

- メニューのカード数・値・見出しが選択に合わせて変わる。青は現在の枠、オレンジは済んだ枠。速度方式のオレンジは「再生済み」であり発話や合格の印ではない。
- 実際のRiveのModel/Speakタイムラインを、説明用の等速1.8秒を速度で割った時間で再生。0.6倍なら波形の進行も遅くなる。同一波形を使って比較する。
- 回数方式では話した場合だけ次の枠へ。未発話なら同じ枠を繰り返す。
- 速度方式では未発話でも次の枠へ。周回中に一度以上話した場合だけ、その周の最後まで再生して完了する。一度も話さなければメニューの先頭へ戻る。
- 「自動で話す」は説明専用。回数方式では各回、速度方式では最初の1回だけ発話を代行し、残りの再生を見せる。
- 完了時は次フレーズへの案内を表示して止める。「もう一度試す」で再実行。
- 設定切り替えは比較用に先頭へ戻す。音声・マイク・採点は使わない。実アプリの発話成立を「話す」操作で模式化している。
- 画面外と非表示タブは休止。動きを減らす設定なら停止状態で開始。読み込み失敗時もメニュー比較を利用可能。

Riveは既存の `practice-timing.riv` を共有。メニューと字幕はHTMLで構成。`static/practice-difficulty/flow.js` が回数／速度方式の遷移、`difficulty.js` が表示とRiveを制御する。
