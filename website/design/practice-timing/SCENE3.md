# 場面3：フレーズとレッスンの二重ループ

ホームの場面2の直後、`#feature-speech-detection` に追加。3枚のフレーズカードの小さな反復矢印と、全体を囲む大きな戻り矢印を同時に見せる。操作するたびに別の説明ページへ移る必要はない。

- フレーズごとの回数を1〜3回で変更。初期値は2回。
- 話し終えると現在のカードの回数を1つ増やす。目標未達なら同じカード、達成したら次のカードへ。
- 無発話でのお手本の繰り返しは回数に含めない。
- 3枚目が完了すると大きな矢印を強調し、リピートONなら先頭へ戻る。OFFなら停止。
- 周回表示と各カードの回数はデモ内の進行表示。アプリのメダルや通し回数ではない。
- 「自動で話す」で一連の動きを見ることも可能。これは説明専用の操作であることを補足する。
- 設定変更は先頭へリセット。一時停止、最初から、ゆっくり表示にも対応。
- 音声・マイク・録音・採点は使わない。

口パク、スピーカーの音波、上下の波形は場面1の `practice-timing.riv` を共有。ループ図はHTML/SVGで描画し、ブラウザ側の同じ時計に合わせて強調する。回数やフレーズ名はRive内に固定しない。

アプリの `docs/unified_practice.md` の回数方式・フレーズ単位を説明用に単純化。無発話で回数を消費しない挙動に合わせる。速度方式と難易度別の設定はここでは省略する。

確認：ホーム上で無発話の回数保持、1/2回時に同じフレーズに留まること、自動進行で複数周、リピートOFF・1回設定で3枚すべて1/1回になり停止、一時停止とリセットを確認。埋め込み幅335pxで横はみ出しなし。JavaScript/Pythonの構文確認と `git diff --check` を実施。
