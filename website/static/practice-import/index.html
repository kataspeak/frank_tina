音源の取り込みと区切り編集について

自分の音源の取り込みと編集はスマホ版（iOS / Android）の機能です。端末のファイルを選ぶか、アプリ内ブラウザで出版社サイトから音源をダウンロードして取り込めます。1音源は最大20分です。

アプリは音声の切れ目をもとに、フレーズや短い区切りを自動で作ります。自動の区切りが必ず意味のまとまりになるわけではありません。そのまま練習を始められ、必要なら音源を聞きながら分割・境界の移動・結合で調整できます。

このページは固定のサンプル波形と区切りを使う説明用デモです。ファイルの選択・送信・保存や、実際の音声解析は行いません。本文や翻訳の自動生成を示すものでもありません。編集ボタンとスライダーはウェブで試しやすくした操作で、アプリの編集画面そのものではありません。

練習は選択した1区間の繰り返しに省略しています。波形と再生時間は模式的に示し、短い区切りほど短いアニメーションで練習します。デモの編集範囲は最短0.6秒・最大8区切りに制限しており、アプリの制限値を表すものではありません。
