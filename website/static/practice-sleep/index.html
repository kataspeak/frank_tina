実際のアプリでは？

就寝前練習はスマホ版（iOS / Android）の機能です。発話がない状態が1・3・5分の設定時間続くと、自動で停止します。初期設定は3分。お手本の再生中も無発話時間を計測し、声を検知すると計測をやり直します。

練習の上限時間は15・30・60・90分から設定できます（初期設定60分）。このデモでは60分相当を上限にしています。停止時に通知音や結果画面を出さず、あとからアプリを開いたときなどに結果を確認できます。

「発話時間（推定）」は、声に出していた時間の目安です。眠るまでの時間や睡眠の質を測るものではありません。朝の38分24秒は、まとまった時間練習した夜の説明用の例です。このページを操作した時間から計算した数値ではなく、実際の練習記録としても保存されません。睡眠そのものではなく、声が途切れた時間をもとに停止します。

ティナが起こす場面は、このウェブサイトの説明用の演出です。アプリの目覚まし機能を示すものではありません。動きを減らす設定でも、ボタンで夜から朝の流れを試せます。
