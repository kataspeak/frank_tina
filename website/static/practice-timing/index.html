このデモについて

3フレーズを順に練習する説明用のデモです。回数方式・フレーズ単位・各1回の例です。発話しない間は同じフレーズを繰り返し、お手本と発話が両方終わると次へ進みます。3つ目の後は最初へ戻ります。フレーズごとに異なる模式的な波形を使い、上下では同じ形を表示しています。発音の採点や録音は行いません。

間隔は違いを体験しやすいように0〜2秒に広げています。アプリの固定間隔は0.5〜1秒です。音声の長さに合わせた間隔も選べます。「ゆっくり表示」では動きだけを半分の速さにします。
