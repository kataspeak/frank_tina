## これは何？ / What is this?

CEFR 4レベル（A1・A2・B1・B2）× 各60話 = **全240話**からなる、
一本の連続シットコム台本です。礼儀正しい人造人間 **フランク（Frank）** と、
別の星から来た好奇心旺盛な **ティナ（Tina）** の出会いから関係の深化までを、
再生順＝物語の時系列として描きます。全英文に日本語対訳付き。

この台本は、発話トレーニングアプリ **[FrankenDojo](https://seiwait.com)** の
オリジナル教材です。実際にシャドーイングを体験できる Web 版は
**[frankendojo.com](https://frankendojo.com)** で公開しています
（最初の10話は登録不要で体験可能）。

A single continuous sitcom in four CEFR levels (A1/A2/B1/B2),
60 episodes each — **240 episodes total** — with Japanese translations.
It is the original courseware for the shadowing-training app **SayDojo**.
